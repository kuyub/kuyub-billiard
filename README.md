# Kuyub Billiard

Website profil dan menu untuk usaha billiard dan cafe "Kuyub Billiard". Project ini dibuat sebagai tugas mata kuliah Pengenalan Pemrograman.

## Live Demo
https://kuyub.github.io/kuyub-billiard/Billiard/

## Fitur
- Halaman beranda (profil usaha)
- Halaman cafe dengan daftar menu bergambar
- Halaman login (tampilan)
- Tampilan dengan CSS terpisah untuk tiap halaman

## Teknologi
- HTML
- CSS
- Deploy menggunakan GitHub Pages

## Struktur Folder
- `index.html`, `cafe.html`, `login.html`: halaman website
- `asset/css/`: file styling
- `gambar/`: gambar menu dan background
